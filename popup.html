Typing and voice
Find & Replace guide
  • Click inside any text box that has some text, then press Ctrl+F to find, or Ctrl+H to find and replace. Every match is highlighted.
  • Enter / Shift+Enter go to the next / previous match. In the Replace box, Enter replaces one and Ctrl+Alt+Enter replaces all. Esc closes it. Replacing can be undone with Ctrl+Z.
  • Aa match case, ab whole word (works with Bangla kar and fola), .* regular expression ($1 and \n work in Replace), বা phonetic: type roni to find রনি, and in Replace type rahat to insert রাহাত (capital R means ড়). AB keeps the letter case.
  • If you select several lines first, it searches only inside your selection (the ≡ button turns this on or off).
  • Copy, cut, paste and select all (Ctrl+C / X / V / A) work in both boxes, even on sites that block copy and paste.
  • An empty box, a password box, Google Docs and code editors like VS Code keep their own Ctrl+F.
Phonetic typing guide
  • Type in English letters and press Space: tumi kemon acho → তুমি কেমন আছো.
  • While you type, a list of spellings appears. The first one is used by default. Press ↓ / ↑ to choose another (the last item keeps your English letters), then Space or Enter. You can also click an item. Esc closes the list.
  • Press Backspace right after a word was converted to get your English letters back.
  • . after a word → ।
  • Small/capital letters differ: t ত, T ট · th থ, Th ঠ · d দ, D ড · n ন, N ণ · s স, S শ, Sh ষ · r র, R ড়
  • ch / chh → ছ, c → চ · ng → ং, Ng → ঙ · ^ → ঁ
  • Vowels: a া/আ, i ি/ই, u ু/উ, e ে/এ, oi ৈ, ou ৌ. A final o after a letter gives ো (valo → ভালো); a middle o is silent (kemon → কেমন). Use capital O for ো anywhere (tOmar → তোমার).
  • Joined letters: sundor → সুন্দর, prem → প্রেম, dhonyobad → ধন্যবাদ. Use rr for reph (korrmo → কর্ম). Use a backtick ` to stop two letters joining.
  • Not converted: words after @ / _ #, and links (http, www). For English text, turn it off with Alt+B.
  • Common words come from a built-in word list, so the right spelling is first: jonno → জন্য, tomar → তোমার, dhonnobad → ধন্যবাদ.
  • A large Bangla word list moves real words to the top of the list: proshno → প্রশ্ন, poribar → পরিবার.
  • Suggestions appear while you are still typing: dhonno shows ধন্যবাদ, and shompo offers সম্পর্ক, so long words need fewer keys. They start after 3 letters and sit below the normal spellings, so Space still gives the usual word.
  • The spelling you choose is remembered: next time you type the same word, your choice is first in the list.

Voice command list
  • দাঁড়ি (dari) → ।
  • কমা (koma) → ,
  • প্রশ্নবোধক চিহ্ন (proshnobodhok chinho) → ?
  • বিস্ময়সূচক চিহ্ন (bismoyshuchok chinho) → !
  • কোলন (kolon) → :   সেমিকোলন (semikolon) → ;
  • হাইফেন (hyphen) / ড্যাশ (dash) → -
  • নতুন লাইন (notun line) → Enter
  • নতুন অনুচ্ছেদ (notun onucched) → blank line between paragraphs
  • In English mode say: period, comma, question mark, exclamation mark, colon, semicolon, hyphen, new line, new paragraph
